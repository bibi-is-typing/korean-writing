# korean-writing

> AI 티 나는 한국어를 자연스러운 한국어로. 장르마다 다르게.

한국어 텍스트를 받아 AI 안티패턴을 제거하고, **장르에 맞는 구조와 톤으로** 다시 쓰는 Claude 스킬입니다.

원작자의 의도와 톤은 유지하고, 부자연스러운 표면만 다듬습니다.

---

## 무엇을 하는가

이런 요청에 발동합니다.

- "이 글 좀 자연스럽게 다듬어줘."
- "AI가 쓴 티가 너무 나."
- "톤이 어색해. 리라이팅 해줘."
- "이메일 다듬어줘."
- "공지 다시 써줘."
- "제안서 정리해줘."
- "피드백 톤 좀 봐줘."
- "링크드인 포스트 손봐줘."

자동으로 다음을 제거합니다.

- Em dash (—, –)
- 빈 호칭 ("여러분", "당신")
- 빈 강조어 ("정말", "매우", "굉장히")
- 클리셰 ("성장했다", "혁신적인")
- 가정형 ("할 뻔했다", "였을 것이다")
- 영어 calque ("결국에는", "본질적으로", "기본적으로")
- 본문 이모지 (장르에 따라)
- 복문 과다, 단락 호흡 부족

그리고 **장르별로 구조와 톤을 다르게 적용**합니다.

---

## 7가지 장르

장르마다 핵심 구조, 톤, 길이가 다릅니다.

| 장르 | 무엇을 위한 글 | 사용 예 |
|---|---|---|
| **blog** | 블로그/에세이 (깊은 인사이트) | 본격 분석, 회고록 |
| **linkedin** | 링크드인 포스트 (중간 길이) | 업계 인사이트, 짧은 분석 |
| **business-comm** | 업무 이메일/메시지 | 요청, 보고, 공유 |
| **gov-doc** | 거버넌스 문서 | 제안서, 정책서, 의사결정 |
| **announcement** | 공지/모집 | 디스코드 공지, 이벤트 |
| **feedback** | 피드백/리뷰 | 자료 응답, 멘토링 |
| **report** | 기술/리포트 | PRD, 분석 보고서 |

---

## 워크플로우 (7단계)

```
① INTAKE     원문 받기 + 컨텍스트 확인
② AUDIT      공통 안티패턴 자동 검출
③ CLASSIFY   글 장르 분류 (7가지 중)
④ LOAD       해당 장르 references 파일 로드
⑤ REWRITE    공통 룰 + 장르 룰 동시 적용
⑥ VERIFY     공통 + 장르 체크리스트 통과 확인
⑦ PRESENT    Before/After + 변경 요약
```

---

## 핵심 원칙 (공통)

모든 장르에서 다음 다섯 가지를 동시에 만족시킵니다.

1. **AI 안티패턴 0건.** 자동 검출과 제거.
2. **한 문장 한 의미.** 긴 복문을 짧은 단문으로 분리.
3. **추상을 구체로.** 모호한 표현을 숫자, 명사, 행동으로 변환.
4. **목소리 보존.** 원작자의 톤과 단어 선택을 존중. 표면만 다듬음.
5. **MECE 구조.** 중복 없이, 빠짐없이. 한 단락 한 메시지.

## 설치

### Claude Desktop 또는 Claude Code

```bash
git clone https://github.com/[사용자]/korean-writing.git
cp -r korean-writing/korean-writing ~/.claude/skills/
```

### `.skill` 패키지로 사용

`releases/` 의 `.skill` 파일을 다운로드해서 Claude 클라이언트에 import.

## 사용 예시

### 입력

```
이메일 다듬어줘.

"안녕하세요! 다름이 아니라 — 지난번에 말씀드렸던 그 건 관련해서 메일 드립니다.
기본적으로 이 프로젝트는 정말 중요한 프로젝트이고, 본질적으로 많은 분들의 협조가
필요한 상황이에요. 어쩌면 다음 주 정도까지는 결정이 나야 할 것 같은데, 가능하시면
빠른 시일 내에 회신 부탁드립니다."
```

### 출력

```
## 리라이팅 완료

장르: business-comm (업무 이메일)
검출된 안티패턴: Em dash 1건, 빈 강조어 2건, 영어 calque 3건, 모호 표현 3건

### After

안녕하세요. 지난번 논의한 마케팅 캠페인 예산 건 관련 메일입니다.

6월 출시 일정을 맞추려면 다음 주 화요일(6/3)까지 예산 승인이 필요합니다.
예산 규모는 1,200만 원입니다.

6/3 오전까지 회신 부탁드립니다. 회신 받는 대로 캠페인 제작에 착수하겠습니다.

### 주요 변경 사항
- "다름이 아니라" 삭제 → 본론 직진
- Em dash를 마침표로 변환
- "정말", "본질적으로", "기본적으로", "결국에는" 삭제
- "빠른 시일 내에" → 구체적 날짜 "6/3 오전까지"
- 맥락 추가 (어떤 프로젝트인지)
- 다음 단계 명시 (회신 후 캠페인 제작 착수)
```

## 무엇을 하지 않는가

- 원작자의 의도를 바꾸지 않습니다.
- 사실 정보를 추가하거나 빼지 않습니다.
- 원본에 없는 새로운 주장이나 결론을 만들지 않습니다.
- 모호한 부분이 있으면 추측하지 않고 사용자에게 묻습니다.
- 장르를 무작정 추측하지 않습니다. 신호가 약하면 확인합니다.
