# 장르: linkedin (링크드인 포스트)

업계 인사이트, 회고, 짧은 분석을 위한 글.
800-2,000자의 중간 길이 글.

---

## 정의

다음 중 하나에 해당하면 linkedin 장르.

- 업계나 직무에 대한 짧은 인사이트.
- 본인 경험을 보편화한 회고.
- 특정 사건이나 결정에 대한 분석.
- 도서/콘텐츠 리뷰의 요약 인사이트.

블로그보다 짧고, SNS 포스트보다 긴 형식.

---

## 핵심 구조

후킹 + 맥락 + 인사이트 + 마무리 4부 구조.

### 후킹 (첫 1-2 문장)

- 가장 중요한 부분. 스크롤을 멈추게 해야 한다.
- 단정, 의외의 관찰, 도발적 질문 중 선택.
- "오늘은", "최근에" 같은 약한 도입어 금지.

### 맥락 (1-2 단락)

- 후킹 다음에 필요한 배경.
- 본인의 어떤 경험/관찰에서 나왔는지.
- 구체적이고 짧게.

### 인사이트 (2-3 단락)

- 글의 핵심 메시지.
- 보편화 가능한 통찰로 풀어냄.
- 사례 1-2개 포함.

### 마무리 (1 단락)

- 다음 행동, 질문, 또는 함축적 마무리.
- 과도한 hashtag 금지.
- CTA 강요 금지 ("팔로우해주세요" 등).

---

## 톤 / 길이 / 종결어

| 항목 | 가이드 |
|---|---|
| 전체 길이 | 800-2,000자 |
| 한 단락 | 2-4 문장 |
| 종결어 | ~다 (단정) + ~요/예요 혼용 |
| 톤 | 단정적, 인사이트풀, 약간 도발적 |
| 첫 문장 | 후킹 필수. 약한 시작 금지 |
| 단락 | 모바일에서 읽기 쉽게 짧게 |

---

## 장르 특수 안티패턴

공통 안티패턴 외에 linkedin 장르에서 특히 조심할 것.

| 패턴 | 왜 금지 |
|---|---|
| "오늘 정말 ___ 했어요" 시작 | 약한 후킹. 스크롤 통과됨 |
| "여러분은 어떠신가요?" 마무리 | 빈 질문. 인터랙션 강요 |
| #해시태그 5개 이상 | 본문 신뢰도 떨어짐 |
| "팔로우/좋아요 부탁드립니다" | 광고 톤. 신뢰 잃음 |
| 과도한 줄바꿈으로 길이 부풀리기 | 정보 밀도 낮아짐 |
| 인용구로만 채우기 | 본인 관점 부재 |
| "오늘의 인사이트" 식 라벨 | 클리셰 마케팅 톤 |

## Before / After

### Before

```
안녕하세요 여러분! 오늘은 정말 중요한 인사이트를 공유하고 싶어요 😊

최근에 PM으로 일하면서 정말 많은 것을 배우고 있는데요, 특히 사용자 인터뷰의
중요성을 다시금 깨닫게 되었습니다 — 우리가 만든다고 생각했던 것과 실제 사용자가
원하는 것 사이에는 매우 큰 간극이 있다는 것을 알게 되었어요.

어쩌면 모든 PM 분들이 한 번쯤 겪게 되는 경험일 것 같은데요, 여러분은 어떠신가요?
인사이트가 가득한 한 주였습니다!

#PM #사용자인터뷰 #성장 #회고 #인사이트 #스타트업
```

### After

```
PM이 되고 6개월. 가장 비싼 학습은 사용자 인터뷰를 미룬 거였다.

지난 분기에 새 기능 3개를 출시했다. 모두 우리 팀이 "사용자가 원할 것" 이라고
가정한 것들이었다. 출시 후 6주가 지났을 때 이 기능들의 사용률은 7%였다.

이번 분기에 사용자 인터뷰 12건을 진행했다. 알게 된 건 단순했다.
우리가 풀고 있다고 생각했던 문제가 사용자가 겪는 진짜 문제가 아니었다.

우리가 만든 게 아니라 사용자가 원하는 걸 만들고 있는지, 매주 한 번은 멈춰서
확인해야 한다는 걸 이번 분기에 배웠다.

#PM #사용자인터뷰
```

## 체크리스트

linkedin 장르 완료 후 확인.

- [ ] 첫 문장이 후킹 (약한 도입어 없음)
- [ ] 전체 800-2,000자
- [ ] 한 단락이 2-4 문장
- [ ] 본문 이모지 최대 1개
- [ ] Hashtag 최대 3개
- [ ] "팔로우/좋아요 부탁" 류 광고 톤 없음
- [ ] "여러분은 어떠신가요?" 빈 질문 없음
- [ ] 구체적 수치나 사례 최소 2건
- [ ] 마무리에 보편화된 인사이트 또는 다음 행동
