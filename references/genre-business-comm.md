# 장르: business-comm (업무 이메일 / 메시지)

업무 요청, 보고, 공유를 위한 글.
이메일, 슬랙, 카카오톡 업무 메시지 포함.

---

## 정의

다음 중 하나에 해당하면 business-comm 장르.

- 업무 관련 요청 (검토, 승인, 데이터 공유 등).
- 업무 진행 상황 보고.
- 결정 사항 공유.
- 회의 일정 조율.
- 외부 협력 제안.

수신자가 명확하고, 액션이 필요한 글.

---

## 핵심 구조

맥락 + 요청/내용 + 기한/다음 단계 3부 구조.

### 1. 맥락 (1-2 문장)

이 메시지가 왜 필요한지 배경. 수신자가 모를 수 있다는 전제로.

### 2. 요청 또는 내용 (구체적으로)

무엇을 해달라는지, 무엇을 알려야 하는지 명확히.
"검토", "확인" 같은 모호한 표현 금지.

### 3. 기한 및 다음 단계

- 구체적 날짜 (YYYY-MM-DD 또는 요일 + 시간).
- 회신 후 무엇이 진행되는지.

---

## 메시지 유형별 템플릿

### 요청 메시지

```
[맥락 1-2 문장: 왜 이 요청이 필요한가]

[구체적 요청: 무엇을 해달라는 건가]

[기한 및 다음 단계: 언제까지, 회신 후 무엇이 진행되는지]
```

### 업데이트/공유 메시지

```
[요약: 핵심 1 문장]

[배경: 왜 이 업데이트가 필요한가]

[구체적 내용: 무엇이 변경/진행되었나]

[영향: 수신자가 알아야 할 것]
```

### 피드백 요청

```
[무엇에 대한 피드백인가]

[구체적 질문 2-3개]

[기한 및 활용 계획]
```

---

## 톤 / 길이 / 종결어

| 항목 | 가이드 |
|---|---|
| 전체 길이 | 200-500자 (이메일), 100-200자 (슬랙) |
| 한 단락 | 1-3 문장 |
| 종결어 | ~합니다 / ~입니다 (격식) |
| 톤 | 격식 있게, 명확하게, 친절하게 |
| 인사말 | 최소화. 본론 빨리 |
| 마무리 | "확인 후 회신 부탁드립니다" 등 다음 단계 명시 |

---

## 장르 특수 안티패턴

공통 안티패턴 외에 business-comm 장르에서 특히 조심할 것.

| 패턴 | 변환 방식 |
|---|---|
| "다름이 아니라" | 삭제. 본론으로 직진 |
| "가능하시면" | "X월 X일까지" 같은 구체적 기한으로 |
| "빠른 시일 내에" | 구체적 날짜로 |
| "검토 부탁드립니다" | 무엇을 검토할지 명시 (예산? 일정?) |
| "확인 부탁드립니다" | 무엇을 어떻게 확인할지 명시 |
| "회신 부탁드립니다" | 회신 기한 + 회신 후 무엇이 진행되는지 |
| "감사합니다 :)" 같은 이모지 | 격식 톤에 맞지 않음 |
| "혹시" 남발 | 핵심 약화. 단정적으로 |

## 필수 포함 요소

다음 3가지가 모두 있어야 한다.

### 1. 맥락 (Why)

수신자가 이 프로젝트를 모를 수 있다는 전제로 시작.

❌ "어제 논의한 대로 A안으로 진행하겠습니다."
✅ "결제 플로우 개선 프로젝트 관련입니다. 지난주 분석에서 3단계 인증이 이탈의 주요 원인으로 확인되어, 2단계로 간소화하는 A안으로 진행하겠습니다."

### 2. 구체성 (What)

"검토" 같은 모호한 표현 금지.

❌ "첨부 문서 검토 부탁드립니다."
✅ "첨부 마케팅 계획서에서 두 가지 확인 부탁드립니다. 1) 예산 배분이 Q2 목표와 맞는지, 2) 일정이 제품 출시 계획과 충돌하지 않는지."

### 3. 기한 (When)

"빠른 시일 내" 같은 모호한 표현 금지.

❌ "급하니 빨리 회신 부탁드립니다."
✅ "목요일(1/18) 오전 11시까지 회신 부탁드립니다. 이 피드백을 반영해 오후 클라이언트 미팅에서 최종안을 공유할 예정입니다."

---

## 우선순위 분리

여러 요청이 섞이면 우선순위 분리.

❌ Before:
"기획서 검토하고, A 기능 개발 일정도 확인해주세요. 그리고 B 관련 데이터도 있으면 공유 부탁드립니다. C에 대한 의견도 궁금합니다."

✅ After:
```
우선순위 1 (금요일 오전까지 필수)
- 기획서 3페이지 예산안 승인 여부
- A 기능 개발 완료 예상일 (클라이언트 미팅 일정 잡기 위함)

우선순위 2 (다음주 중)
- B 관련 데이터 (있으면 공유, 없으면 스킵)
- C에 대한 의견 (시간 나실 때)
```

---

## 제목 작성 (이메일)

제목도 맥락 포함.

❌ "질문 있습니다"
✅ "Q2 예산 배분 관련 질문 (1/20까지 회신 요청)"

❌ "확인 부탁드립니다"
✅ "마케팅 계획서 예산 항목 확인 요청 (1/19 금요일까지)"

## Before / After

### Before

```
안녕하세요!

다름이 아니라 — 지난번에 말씀드렸던 그 건 관련해서 메일 드립니다.
기본적으로 이 프로젝트는 정말 중요한 프로젝트이고, 본질적으로 많은 분들의
협조가 필요한 상황이에요. 어쩌면 다음 주 정도까지는 결정이 나야 할 것 같은데,
가능하시면 빠른 시일 내에 회신 부탁드립니다.

감사합니다!
```

### After

```
안녕하세요. 지난번 논의한 마케팅 캠페인 예산 건 관련 메일입니다.

6월 출시 일정을 맞추려면 다음 주 화요일(6/3)까지 예산 승인이 필요합니다.
예산 규모는 1,200만 원입니다.

6/3 오전까지 회신 부탁드립니다. 회신 받는 대로 캠페인 제작에 착수하겠습니다.

첨부한 기획서 3-5페이지에 예산 항목별 상세 내역을 정리했습니다.
확인 후 의견 주시면 반영하겠습니다.
```
